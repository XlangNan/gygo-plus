🔔 钉钉机器人通知

在钉钉群里加一个「自定义机器人」，把 Webhook 地址（和可选的加签密钥）填在这里保存即可， 不需要改 Docker 配置。三种情况会发通知：新增监控时、转存成功时、链接失效时。

🎬 联动 SmartStrm

转存成功后自动 POST 到 SmartStrm 的 Webhook，触发它立即执行指定任务生成/更新 STRM， 不用等它的定时扫描。地址在 SmartStrm「系统设置→Webhook」里获取。

🎯 TMDB 设置

用于「订阅追更」自动查一部剧的总集数。免费申请：themoviedb.org/settings/api， 选 "API Key (v3 auth)" 那个。不填也能用订阅功能，只是总集数要自己手动填。

🎥 Emby 联动

订阅追更扫描时会先查一下 Emby 库里这部剧（按 TMDB ID 匹配）已经有哪些集， 已经在 Emby 里的集不会重复转存——不管这一集是不是 gygo-plus 自己转过去的， 比如你之前用别的方式导进 Emby 的老资源，也会被认出来跳过。 只影响「订阅追更」，跟「分享监控」无关。

📺 订阅追更

适合"同一部剧有好几个人分享、且经常有人分享不全"的场景：建一个订阅、按 TMDB 查总集数（或手填）， 下面挂几条不同人的分享链接，gygo-plus 会依次检查每条链接，把缺的集数转存过来，同一集不管从哪条链接 来的都只转一次，集数收齐就自动停止扫描。
